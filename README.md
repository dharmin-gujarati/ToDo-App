# 📱 ToDo App (iOS)

A simple and intuitive ToDo application built for iOS that helps users manage daily tasks efficiently. This project demonstrates clean architecture, modern Swift practices, and user-friendly UI design.

---

## 🚀 Features

- ✅ Add new tasks
- 📝 Edit existing tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 📋 View all tasks in a clean list
- 💾 Persistent storage (local database / UserDefaults / CoreData)

---

## 🛠 Tech Stack

- **Language:** Swift
- **Framework:** UIKit / SwiftUI
- **Architecture:** MVVM / MVC
- **Storage:** CoreData / UserDefaults
- **IDE:** Xcode
